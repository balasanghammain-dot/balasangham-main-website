# User Journeys

## Journey 1: New Visitor — "What is Balasangham?"

**Persona**: Parent, teacher, or community member hearing about Balasangham for the first time.

```
Homepage
  → Reads hero + introduction
  → Clicks "Learn More" → About (Who We Are)
  → Reads objectives → About / Objectives
  → Curious about history → About / History
  → Sees programs → Programs
  → Sees upcoming event → Events / Conference 2026
  → Checks contact → Contact
```

**Key requirement**: Clear identity communication within 5 seconds of landing. Hero must answer "What is this organization?" immediately.

---

## Journey 2: Activity Seeker — "What does Balasangham do?"

**Persona**: Parent whose child is interested, or a teacher looking for student activities.

```
Homepage
  → Scans programs grid
  → Clicks specific program → Programs / Venalthumbikal
  → Returns to Programs → Browses other programs
  → Checks events → Events (upcoming)
  → Wants to join → Join Us
  → Needs contact → Contact
```

**Key requirement**: Programs must be scannable and clearly described. "Join Us" should be reachable from any page.

---

## Journey 3: Event Attendee — "Tell me about the conference"

**Persona**: Delegate, supporter, or media person looking for conference details.

```
Homepage
  → Clicks featured event card
  → Events / Conference 2026
  → Reads date, venue, theme, historical significance
  → Checks program schedule (if available)
  → Views related media → Media
  → Returns to Events → Views past events
```

**Key requirement**: Event detail page must be comprehensive — date, venue, theme, description. The conference is ONE event, not the entire site.

---

## Journey 4: Researcher / Journalist — "Tell me about this organization"

**Persona**: Journalist, academic, or political researcher.

```
Homepage
  → About → Who We Are
  → About → History (detailed timeline)
  → About → Organization Structure
  → About → Leadership (current office bearers)
  → About → Notable Alumni
  → Publications (Kilikkoodu, Spark)
  → News (recent activities, source links)
  → Contact
```

**Key requirement**: Comprehensive, well-sourced factual content. Source attribution matters. No invented claims.

---

## Journey 5: Malayalam-Speaking Visitor

**Persona**: Malayalam-speaking parent or community member.

```
Homepage (English)
  → Clicks "മലയാളം" toggle
  → Homepage (Google Translated to Malayalam)
  → Navigates normally (all content translated)
  → Encounters original Malayalam content (flag song, slogans, mottos)
    → These remain in original Malayalam, not double-translated
  → Switches back to English if needed
```

**Key requirement**: Language toggle accessible from every page. Original Malayalam content (flag song, mottos, event titles) preserved verbatim. Google Translate applied to English canonical content.

---

## Journey 6: Member / Existing Participant — "What's new?"

**Persona**: Current Balasangham member, unit leader, or active supporter.

```
Homepage
  → Scans latest news
  → Clicks news item → News / Article
  → Checks upcoming events → Events
  → Views new media → Media / Gallery
  → Shares link on social media
```

**Key requirement**: Fresh content visible on homepage. News and events must be current.

---

## Journey 7: Social Media Arrival — "Linked from Facebook/Instagram"

**Persona**: Someone who saw a poster or post on Balasangham Kannur's Facebook and clicked through.

```
Direct link to specific page (event, news, program)
  → Reads content
  → Clicks logo/home → Homepage
  → Explores About
  → Browses Programs
```

**Key requirement**: Every page must be a valid entry point. Organization identity visible on every page (navbar with logo + name). Social sharing metadata (Open Graph) must produce good previews.

---

## Journey Priority Ranking

| Journey | Priority | Rationale |
|---|---|---|
| 1. New Visitor | HIGHEST | Most common — site must explain itself |
| 2. Activity Seeker | HIGH | Drives participation and engagement |
| 3. Event Attendee | HIGH | Time-sensitive, actionable |
| 5. Malayalam Visitor | HIGH | Significant portion of audience |
| 6. Existing Member | MEDIUM | May primarily use Facebook/social |
| 4. Researcher | MEDIUM | Important but less frequent |
| 7. Social Media Arrival | MEDIUM | Valid but secondary entry path |
